# Project summary

## Problem statement

Can launch characteristics such as launch site, payload, orbit and booster generation help explain Falcon 9 first-stage landing success?

## Questions answered

1. How does landing success change over time?
2. Which launch sites show the strongest observed landing performance?
3. How does success vary by orbit?
4. Is payload mass associated with landing outcome?
5. How does booster generation relate to landing performance?
6. What does the launch-site geography look like?
7. Which classification approach performed best in the supplied modeling exercise?

## Outcome

The project combines descriptive analytics with predictive modeling and an interactive dashboard so that a reviewer can move from raw data collection to interpretable decision-oriented insights.
